# Mobile / Маршрут заказа — рабочий макет

Это сохранённая рабочая версия мобильного макета, которая отображается по адресу `http://127.0.0.1:4175/`.

## Где лежит интерфейс

- Основная разметка и логика: `src/Prototype.tsx`
- Стили макета: `src/prototype.css`
- Реальные изображения и брендовые ассеты: `public/assets/content/`
- Контрольный скрин: `implementation-iphone-screen-passed.png`
- Результат визуальной проверки: `design-qa.md`

## Как запустить

```powershell
npm install
npm run dev -- --host 127.0.0.1 --port 4175
```

Папки `node_modules` и `dist` намеренно не сохранены: они генерируются заново и не являются исходниками макета.
