# Журнал решений

Короткий журнал заменяет старые разрозненные планы и аудиты. Подробные снимки остаются в `qa/screenshots/`.

## 2026-08-20 — desktop direction

- Desktop должен продавать B2B-систему владельцу, а не только гостевой заказ.
- Убрано ощущение forced-перелистывания: production desktop использует обычный вертикальный скролл.
- Утверждённый desktop baseline «Продукт в телефоне» остаётся визуальной основой.

## 2026-08-21 — product screens

- В desktop перенесены готовые screens гостя, кассира, кухни и директора из прошлой версии.
- Главным визуальным героем оставлен phone screen, а не растровый screenshot страницы.

## 2026-08-21 — client entry / one bot

- Гостевой старт — реальное клиентское меню.
- Визуальная логика entry point: `QR → Меню → Заказ`.
- Все роли объясняются как режимы одного Mini App, а не как четыре разрозненных приложения.

## 2026-08-21 — director value proposition

- Существующая директорская секция расширена до полного операционного обещания: товары, категории,
  сотрудники, доставка, заказы, клиенты и точки.
- Это добавлено в существующие director/sync sections, без ещё одного длинного feature-блока.

## 2026-08-21 — hero phone pair

- Правая часть hero показывает реальные `<dl-product-screen>`: меню клиента и dashboard директора.
- Сторонний декоративный экран директора убран; масштаб, подпись и наклон телефонов собраны как единая композиция.

## Mobile baseline

Мобильный эталон и рабочая папка внутри `qa/approved-mockups/` сохраняются без изменений. Старые
мобильные планы не являются инструкцией для текущего desktop-прохода.
