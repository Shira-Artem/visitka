# ЮртаНеЖди — лендинг

Сайт-визитка сервиса заказа еды «ЮртаНеЖди»: закажи заранее → забери без очереди или закажи доставку. Работает в Telegram и MAX.

Слоган: **«Не жди. Закажи.»**

## Стек

Статический сайт без сборки и зависимостей — чистые HTML + CSS + Vanilla JS.
Сборка нужна только для деплоя (хэши в именах файлов) и делается одним
скриптом на стандартном Node — ни пакетов, ни `node_modules`.

## Два правила, которые легко нарушить

**1. Порядок `<link>` в `index.html` менять нельзя.** Файлы `sections/*` —
это бывший единый `sections.css`, разрезанный по границам строк. Часть правил
спорит между собой на равной специфичности и разрешается только порядком.
Пример: `.story__stage[data-order-phase="cash"] .story__dots` (story.css)
против `.story__stage[data-order-phase] .story__dots` (story-mobile.css) —
специфичность одинаковая, побеждает тот, кто подключён ниже.

**2. Брейкпоинты живут только в `tokens.css`.** Там объявлена `--bp`
(`desktop` / `compact` / `mobile` / `phone`), а `lib/breakpoints.js` её читает.
В JS нет ни одного числа вроде `981` или `768` — правишь ширину в одном месте.

## Локальный запуск

Разработка — прямо из корня, без сборки:

```bash
python -m http.server 8000
```

Затем открыть http://localhost:8000. Версий `?v=` в `index.html` нет:
сервер отдаёт `Last-Modified`, браузер перепроверяет файл сам.

## Сборка и деплой

```bash
node build.mjs
```

Кладёт в `dist/` те же файлы, но с хэшем содержимого в имени
(`sections/story.6f829e2f.css`), и переписывает ссылки в `index.html` и
в `import`-ах модулей. Ничего не минифицирует и не склеивает — код в
`dist/` читается и отлаживается так же, как исходный.

Деплоить содержимое `dist/`, а не корень репозитория. На хостинге:
хэшированные файлы — `Cache-Control: immutable`, `index.html` — `no-cache`.

## Проверка, что рефакторинг ничего не сломал

`qa/probe.js` снимает геометрию и вычисленные стили всех элементов в 17
точках прокрутки и сравнивает два снимка. В консоли браузера:

```js
var s=document.createElement('script'); s.src='/qa/probe.js'; document.head.appendChild(s);
// на исходном коде, сразу после перезагрузки страницы:
await YJ_PROBE.store('before-390x844')
// после правок — ПЕРЕЗАГРУЗИТЬ страницу и:
await YJ_PROBE.compare('before-390x844')   // total: 0 — ничего не поехало
```

Перезагружать страницу перед каждым снимком обязательно: классы `.in-view` /
`.is-active` навешиваются один раз и не снимаются.

## Точки для наполнения реальными данными

- **QR-код** — блоки `[data-qr]` в `index.html` (2 шт., помечены `<!-- QR-ПЛЕЙСХОЛДЕР -->`). Замени внутренний `<svg>` на реальный QR.
- **Фото еды** — элементы `.dish__img` (сейчас CSS-градиенты). Заменяются на `background-image: url(...)`.
- **Фото заведений** — элементы `.venue__img`. Аналогично.
- **Ссылки Telegram / MAX** — атрибуты `href="#"` у кнопок `.btn--tg` / `.btn--max`.
- **Каталог заведений** — блок `.venues-track`: карточки `.venue` (готовы под рендер из API).
