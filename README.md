# ЮртаНеЖди — лендинг

Сайт-визитка сервиса заказа еды «ЮртаНеЖди»: закажи заранее → забери без очереди или закажи доставку. Работает в Telegram и MAX.

Слоган: **«Не жди. Закажи.»**

## Стек

Статический сайт без сборки и зависимостей — чистые HTML + CSS + Vanilla JS.
Готов к деплою на любой статический хостинг (Nginx, GitHub Pages, Netlify, S3 и т.п.):
достаточно отдавать `index.html` и папку `assets/`.

## Структура

```
.
├── index.html              # разметка страницы (семантика + секции)
├── assets/
│   ├── css/
│   │   ├── tokens.css      # дизайн-токены: цвета, радиусы, тени (тема бренда)
│   │   ├── base.css        # reset, каркас, типографика, утилиты, keyframes
│   │   ├── layout.css      # хром: шапка, навигация, футер, меню, фикс-кнопка
│   │   ├── components.css  # переиспользуемые компоненты (кнопки, карточки, телефон)
│   │   └── sections.css    # композиция секций + адаптив (@media)
│   ├── js/
│   │   └── main.js         # интерактив: reveal, статусы, огненная линия, демо
│   └── img/                # сюда кладём реальные фото еды/заведений
├── legacy/                 # архив прежних версий и черновиков (не деплоится)
└── README.md
```

Стили подключаются по порядку каскада: `tokens → base → layout → components → sections`.

## Локальный запуск

Любой статический сервер, например:

```bash
python -m http.server 8000
```

Затем открыть http://localhost:8000

## Точки для наполнения реальными данными

- **QR-код** — блоки `[data-qr]` в `index.html` (2 шт., помечены `<!-- QR-ПЛЕЙСХОЛДЕР -->`). Замени внутренний `<svg>` на реальный QR.
- **Фото еды** — элементы `.dish__img` (сейчас CSS-градиенты). Заменяются на `background-image: url(...)`.
- **Фото заведений** — элементы `.venue__img`. Аналогично.
- **Ссылки Telegram / MAX** — атрибуты `href="#"` у кнопок `.btn--tg` / `.btn--max`.
- **Каталог заведений** — блок `.venues-track`: карточки `.venue` (готовы под рендер из API).
